黃金 8H 多空混合加碼策略 (方案 B 獨立持倉管理) - MT5 EA 策略邏輯說明
檔名：Gold_8H_Hybrid_Strategy.mq5
================================================================================

一、策略整體架構與定位
--------------------------------------------------------------------------------
本策略為黃金 (XAUUSD) 的多空雙向進階趨勢加碼策略。
在單一波段主部位的基礎上，結合了跨市場美元指數 (DXY) 的超額動能 (Alpha) 以及
日線均線 (20MA vs 60MA) 來控制「金字塔加碼 (Pyramid Order)」。
【方案 B 架構】：主部位與加倉部位之出場與移動停損完全獨立於日線 Regime 趨勢切換，
持倉不會在日線 Regime 切換時被強制砍單，而是由 8H 停損與 8H 動能轉向保護至自然平倉。

二、使用時區與指標參數
--------------------------------------------------------------------------------
1. 執行圖表時區：8 Hours (PERIOD_H8)
2. 交易商品：XAUUSD (主要交易標的)
3. 跨市場參考商品：DXY (美元指數，僅取報價不交易)
4. 指標參數：
   - 8H 均線：30 週期 SMA (PRICE_CLOSE)
   - 8H ATR：14 週期 ATR
   - 日線主趨勢均線：50 週期 SMA (MA50)
   - 日線加倉趨勢均線：20 週期 SMA (MA20) 與 60 週期 SMA (MA60)
5. 下單手數：InpLotSize (主部位與加倉部位各預設 0.01 手)
6. 交易識別號 (Magic Number)：
   - 主部位 Magic Number：InpMagicMain (預設 88880001)
   - 加倉部位 Magic Number：InpMagicPyramid (預設 88880002)

三、核心邏輯與公式細節
--------------------------------------------------------------------------------
1. 日線趨勢過濾器 (Daily Regime Filter - 僅控制新主部位與加倉)
   - 每日新 K 線開盤時讀取昨日數據：
     - 若 Close_D1[1] > MA50_D1[1] => RegimeBull = true (僅允許新開主多單與加多)。
     - 若 Close_D1[1] <= MA50_D1[1] => RegimeBull = false (僅允許新開主空單與加空)。

2. 跨市場超額動能 Alpha 計算 (Alpha Momentum Filter)
   - 1日報酬差 Alpha_1   = (Gold_Ret_1d) - (DXY_Ret_1d)
   - 5日報酬差 Alpha_5   = (Gold_Ret_5d) - (DXY_Ret_5d)
   - 10日報酬差 Alpha_10 = (Gold_Ret_10d) - (DXY_Ret_10d)
   - 加倉許可判定：
     - 允許加多 (PyramidLongOK)：(Alpha_1 > 0) 且 (Alpha_5 > 0) 且 (Alpha_10 > 0) 且 (Daily MA20 > Daily MA60)
     - 允許加空 (PyramidShortOK)：(Alpha_1 < 0) 且 (Alpha_5 < 0) 且 (Alpha_10 < 0) 且 (Daily MA20 < Daily MA60)

四、進場與出場規則 (方案 B 邏輯)
--------------------------------------------------------------------------------
1. 多頭持倉管理 (hasMainLong == true，獨立執行，不受 Regime 限制)：
   - 多單全數平倉條件：當前 8H 收盤價 < 主停損價 OR sig_long_8h == false (8H 動能轉空)
     => 滿足任一條件強制同時平倉主多單與加多單，清空所有停損價。
   - 移動停損 (Trailing Stop Up)：
     若 8H 收盤價 Close_8H[1] > 前一根最高價 High_8H[2] (創新高)：
     新停損 = Min(Low_8H[1], Low_8H[2]) - 1.0 * ATR14_8H[1]
     若 新停損 > 主停損價 => 上調主部位停損價；加多單停損亦同步上調。
   - 加多單獨立停損與加碼建倉：
     - 獨立停損：當前收盤跌破加倉停損價 (PyramidStopPrice) 但未跌破主停損價 => 僅平倉加多單。
     - 加碼建倉：已持主多單、無加多單、InpEnablePyramid == true、PyramidLongOK == true、g_RegimeBull == true 且總持倉 < 2 => 買入加多單。

2. 空頭持倉管理 (hasMainShort == true，獨立執行，不受 Regime 限制)：
   - 空單全數平倉條件：當前 8H 收盤價 > 主停損價 OR sig_long_8h == true (8H 動能轉多)
     => 滿足任一條件強制同時平倉主空單與加空單，清空所有停損價。
   - 移動停損 (Trailing Stop Down)：
     若 8H 收盤價 Close_8H[1] < 前一根最低價 Low_8H[2] (創新低)：
     新停損 = Max(High_8H[1], High_8H[2]) + 1.0 * ATR14_8H[1]
     若 新停損 < 主停損價 => 下調主部位停損價；加空單停損亦同步下調。
   - 加空單獨立停損與加碼建倉：
     - 獨立停損：當前收盤突破加倉停損價 (PyramidStopPrice) 但未突破主停損價 => 僅平倉加空單。
     - 加碼建倉：已持主空單、無加空單、InpEnablePyramid == true、PyramidShortOK == true、g_RegimeBull == false 且總持倉 < 2 => 賣出加空單。

3. 新建主部位邏輯 (當前無任何持倉 totalEAPos == 0 時執行)：
   - 若 RegimeBull == true 且 sig_long_8h == true => 買入主多單，設定初始停損。
   - 若 RegimeBull == false 且 sig_long_8h == false => 賣出主空單，設定初始停損。

五、風控機制與持久化防護 (Risk Control & Resilience)
--------------------------------------------------------------------------------
1. 嚴格持倉上限：總持倉數上限為 2 筆，若超過 2 筆即判定異常並全數強制平倉。
2. 獨立 Magic Number 隔離：主部位 (InpMagicMain) 與加倉部位 (InpMagicPyramid) 完全獨立識別。
3. 全局狀態與歷史軌跡重構：主停損價 (MainStop) 與加倉停損價 (PyramidStop) 均寫入 GlobalVariable。
   EA 重建或重啟時自動動態重構，從歷程逐筆 8H K 線復原真實移動停損價。
